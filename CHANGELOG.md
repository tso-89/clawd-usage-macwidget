# Changelog

## 1.0.0

- First macOS release: a native port of [clawd-usage-winwidget](https://github.com/Enhed/clawd-usage-winwidget) 1.12.3.
- Menu bar item with the session percentage, floating widget with session, week and Fable limits, sessions, service status and account.
- Clawd with every animation, moods, hearts, skins and developer mode; the sky with real sun, moon and weather; themes.
- Details: 24h / 7d stats, the 7-day limits chart and top projects, Claude Code and widget versions.
- Settings, including Claude Code's own settings.json.
- Clawd's panel: tips about the Mac, chat, reminders, lists, recurring tasks and his own Remote Control session.
- Pin the widget to the desktop, under other windows.
- Six more skins: pirate, Viking, ghost, robot, frog and pumpkin.
- Tools a task asks for in a chat reply need your Allow first.
- Signed and notarized, as a drag-to-Applications DMG.
